About

I am a software engineer with three years of production experience, now studying for an MS in Computer Science at UT Dallas on the Intelligent Systems track. Before graduate school I spent two years at Reliance Jio Platforms, where I ran daily scrum for a 30-engineer program and owned two modules end to end, and then a year as the only engineer at a three-person startup in Germany, where I built the web platform, the React Native app, the data models and the CI that shipped them.

Most of what I enjoy sits on the backend: data models, APIs, and the infrastructure that keeps them honest. I write a lot of tests, and I like systems that a stranger can verify without taking my word for anything.

Projects

Job Sentinel

A local-first career platform that collects job postings from several sources, scores how well each one fits a profile using a local language model, and tracks the whole application pipeline from saved posting to offer. No user data leaves the machine it runs on.

  • FastAPI backend with a Next.js interface and a Typer command line client
  • Browser extension that clips a posting straight into the tracker
  • Over 500 tests and security scanning gates in continuous integration

ATLAS

A multi-agent orchestration system for research work. An orchestrator routes a goal to the right team of specialist agents, and a separate critic agent checks the result before anything is marked done.

  • Three memory tiers: an episodic ledger, a semantic store and versioned playbooks
  • Three interchangeable runtimes behind one typed protocol
  • Actions that touch the host machine are gated in code, not in prompts

Learn More

Parkify

An automated parking system that reads vehicle number plates from camera frames. I led the technical side of this undergraduate project: dataset collection, model selection, training and the integration that joined three separate pieces into one pipeline.

  • YOLOv5 plate detector trained to 95.45% mAP on a custom dataset
  • Character recognition CNN over 36 classes at 89.66% accuracy
  • OpenCV preprocessing for deskew and character segmentation
